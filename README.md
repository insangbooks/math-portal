# Math Vault

DESIGN.md의 어두운 표면, 구리색 분류 레이블, 세리프 제목, 가는 테두리와 둥근 버튼을 적용한 로컬 수학 게임 포털입니다. 유료 Ivy Presto 대신 OS 기본 Georgia/바탕 계열을 사용합니다.

## 실행

이 폴더에서 `npm start` 실행 후 http://127.0.0.1:4173 을 엽니다. Node.js 18 이상이 필요합니다. 종료는 Ctrl+C입니다. 설치할 외부 패키지가 없습니다.

## 기능

- 계산·수열·연립방정식 게임, 각 5문제와 해설
- 분류 필터, 제목/설명 검색, 날짜별 동일한 오늘의 도전
- 완료 게임 수, 정답 수, 정답률과 최고 점수의 브라우저 저장 및 초기화
- 모바일 레이아웃, 키보드 입력, 모달과 상태 알림

## 안전 및 제한

서버는 127.0.0.1에만 바인딩합니다. 공개 배포·외부 요청·분석 도구·로그인·개인정보 수집을 포함하지 않습니다. 저장소에는 합산한 게임 통계만 저장합니다. 저장소 실패 시 메모리에서만 기록합니다. 브라우저 데이터를 삭제하면 기록도 사라집니다. 중간에 닫은 게임은 기록하지 않습니다. 점수는 클라이언트에서 처리하므로 경쟁용 검증 점수가 아닙니다.

서버는 명시된 정적 파일만 제공하며 CSP와 MIME 검사 헤더를 사용합니다. 사용자 검색·답변을 HTML에 삽입하지 않습니다. 게임 답변과 저장된 기록에 숫자 검증을 적용합니다. `npm run check`로 문법 검사를 실행합니다.
